# Protocolo para fotografías e historias reales

Este documento permite completar la Fase C sin recurrir a fotografías de stock que aparenten ser beneficiarios, imágenes generadas de personas o testimonios inventados.

## Requisitos antes de publicar

- [ ] Consentimiento informado, específico y verificable.
- [ ] Autorización diferenciada para imagen, voz, nombre y testimonio.
- [ ] Finalidad, canales, duración y posibilidad de revocatoria explicadas.
- [ ] Evaluación reforzada cuando participen niñas, niños, adolescentes o personas en situación de vulnerabilidad.
- [ ] Confirmación de que la publicación no genera riesgos de seguridad, estigmatización o revictimización.
- [ ] Relación real entre la imagen, el territorio, el programa y la historia descrita.
- [ ] Archivo original y autorización conservados en el repositorio institucional seguro, no en el repositorio público de código.

## Criterios visuales

1. Mostrar participación y dignidad; evitar imágenes de sufrimiento usadas como decoración.
2. Preferir escenas reales de colaboración, aprendizaje y territorio.
3. No fotografiar documentos, historias clínicas, domicilios identificables o pantallas con datos.
4. No modificar una imagen de forma que cambie el sentido de lo ocurrido.
5. Indicar cuando una imagen sea de contexto y no corresponda al proyecto descrito.

## Entrega técnica recomendada

- Hero horizontal: mínimo 1800 × 1100 px.
- Tarjeta editorial: mínimo 1200 × 900 px.
- Formato: AVIF o WebP, con original preservado fuera del repositorio público.
- Peso objetivo web: menos de 250 KB por variante.
- Nombres sin datos personales: `programa-territorio-fecha-01.webp`.

Mientras no exista una imagen que cumpla estos requisitos, el sitio utiliza el patrón institucional de tejido y declara expresamente que el espacio está reservado para historias reales con consentimiento.
