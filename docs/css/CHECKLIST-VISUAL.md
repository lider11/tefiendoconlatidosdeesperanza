# Lista de control visual y accesible

- Inicio, catálogo, detalle de programa, recursos y páginas de participación.
- Anchos de 320, 375, 768, 1024 y 1440 px.
- Zoom de navegador al 200 % sin pérdida de contenido ni desplazamiento horizontal.
- Navegación completa por teclado, incluido menú, pestañas y formularios.
- Indicador de foco visible sobre fondos blancos, petróleo, azul y degradados.
- Formularios: vacío, foco, error, envío, éxito y deshabilitado.
- Movimiento normal y `prefers-reduced-motion: reduce`.
- Contraste de textos pequeños, bordes, estados y controles.
- Comparación antes/después en las rutas críticas antes de retirar CSS heredado.
