# Documentos pendientes para cerrar la auditoría SEO

Este directorio reúne los insumos que deben completar y aprobar las áreas responsables antes de publicar información institucional, configurar analítica o afirmar resultados y alianzas.

## Orden recomendado

1. Completar `01-ficha-institucional-y-gobierno.md`.
2. Validar `02-politicas-y-transparencia.md` con el responsable jurídico.
3. Registrar cada iniciativa en `03-ficha-proyecto-y-evidencia.md`.
4. Confirmar aliados y enlaces en `04-matriz-aliados-y-menciones.md`.
5. Entregar accesos e identificadores indicados en `05-configuracion-analitica.md`.
6. Actualizar mensualmente `06-tablero-seo-mensual.md`.

## Regla de publicación

Ningún nombre de aliado, cifra, testimonio, documento legal, resultado, dirección, teléfono o correo debe publicarse sin fuente, responsable, fecha de vigencia y aprobación expresa. Los datos personales o sensibles requieren base jurídica y controles adicionales.
