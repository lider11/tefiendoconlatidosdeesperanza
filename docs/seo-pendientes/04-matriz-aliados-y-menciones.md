## Control de calidad

- [ ] El nombre coincide con la fuente oficial.
- [ ] La relación está vigente.
- [ ] Existe autorización para usar el logo.
- [ ] El enlace aporta contexto y no fue comprado.
- [ ] No existe intercambio masivo de enlaces.
- [ ] La mención describe con precisión el alcance de la relación.
